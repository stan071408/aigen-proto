- **单日期**与**日期范围**两种字段。
- **自绘日历弹层**（周一起周、可翻月），不用浏览器原生 `type="date"` 弹层。
- 字段规格与文本输入对齐：高度 36、圆角 12、描边 2px `#6b7c94`，主色 `#1c5fc4`。
- 状态：默认、悬停（描边 `#4e627c`）、聚焦/打开（主色描边 + 3px 光圈）、禁用（背景 `#e8edf3`）。
- 选中日期主色填充、白字；今天用底部圆点标记（选中时改为白点）；范围起止之间浅蓝色带 `#e3edfc`。
- 页面同时给出状态示意、静态月历示意，以及可点选回填的交互示例。
