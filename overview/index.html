总览页面 · 三个方案对照

按最新原型稿（v0.17.2）的设计语言出的三个独立总览原型，均为单文件离线 HTML；确定方案后再合并回主原型。

方案 A · 数据看板型 推荐 · v0.2.0

四张 KPI 卡（总生成文章 / 总生成图片 / 待执行任务数 / 失败任务数）+ 近 7 天生成量柱图 + 今日执行流水 + 最近产物 3 张封面卡。

  • 先数据、再流水、最后产物，自上而下三段
  • 失败/等待用颜色区分，一眼找到异常
打开方案 A

方案 B · 工作台时间轴型

左侧今日执行流水（按时间倒序、按日期分组），右侧“今天怎么样 + 快捷开始 + 最近产物”。偏向操作流。

  • 和任务中心的时间轴口径一致
  • 快捷入口省一步跳转
打开方案 B

方案 C · 极简清单型

顶部一行摘要（今日产出/成功/等待/失败/定时待跑），下面两张清单：需要你处理、最近产物，再加一条下一次自动执行。

  • 克制、留白多，适合小屏
  • 先处理、后浏览的两段式
打开方案 C
三个方案共用：左侧导航（图文生成 / 任务中心 / 内容库 / 发布管理（灰）/ 短视频（即将支持））、顶栏状态与示例数据标记、卡片圆角 12–14px、主色 #1c5fc4。数据均为示例。
