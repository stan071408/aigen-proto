## 相对 v0.1.0

1. **第一排 KPI 改为四个汇总指标**：总生成文章（126 篇）、总生成图片（524 张）、待执行任务数（5 个）、失败任务数（2 个）；每张卡下面保留进度条与一行说明（今日增量 / 目标 / 等待原因 / 失败原因）。
2. **第二排左右分屏**：
   - 左：**近 7 天生成量 / 发布量**柱图（文章 / 图片 / 等待 / 失败 四色堆叠）；图例里注明「发布量：BS 端不产生，CS 端回写后再显示」——有发布量时同图再加一组柱子。
   - 右：**今日执行流水**（与任务中心同口径的时间轴：时间、状态胶囊、标题、来源/进度），按日期分组，带「全部 / 执行中 / 失败」分段。
   - 原 v0.1.0 右侧的「待处理」清单取消（待处理信息已由 KPI 的待执行/失败两项 + 流水里的等待态覆盖）。
3. **第三排 最近产物**：三张封面卡加高到 168px，标题与「封面」胶囊在顶部渐层、底栏「时间 · 字数 · 共N张图 + docx + 生成来源」。
