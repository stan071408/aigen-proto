- 目标：把新的内容类型体系接到内容库的查询与过滤上，先出三个方案供项总选。

## 类型体系（按项总口径）

```
内容
├─ 文章
│  ├─ 纯文字稿：原稿 / 差异化稿 / 广度稿 / 深度稿 / 合并稿
│  └─ 图文稿：原图文稿 / 差异化图文稿 / 广度图文稿 / 深度图文稿 / 合并图文稿
└─ 图片
```

- 一级：全部内容 / 文章 / 图片。
- 二级（仅文章）：纯文字稿 / 图文稿。
- 三级：具体稿型（各 5 种）。
- 图片暂不分稿型（项总没给细分，先按单一类型处理，等您补规则）。

## 三个方案

### 方案 A · 两级胶囊

文件：`内容类型筛选-方案A两级胶囊-261115-v0.1.0.html`

- 工具栏三行：内容大类分段（全部/文章/图片）＋搜索；文章类型胶囊（全部文章/纯文字稿/图文稿，带计数）；具体稿型胶囊（多选，带计数）。
- 选「纯文字稿/图文稿」会自动切到「文章」大类；再点具体稿型可多选交叉过滤。
- 优点：三级同屏可见，操作路径最短，点两下就到位。
- 缺点：工具栏占三行高度；稿型多时胶囊会换行。

### 方案 B · 左侧类型树

文件：`内容类型筛选-方案B左侧类型树-261115-v0.1.0.html`

- 左侧固定类型树：全部内容 / 文章 →（纯文字稿 → 5 个稿型；图文稿 → 5 个稿型）/ 图片，每个节点带数量；右侧是搜索、来源筛选、列表，顶部有当前路径提示。
- 优点：层级一眼看清，适合内容量大后的常态浏览；计数让人知道哪类有货。
- 缺点：左侧固定占 250px 宽；单屏可见内容变窄。

### 方案 C · 类型多选弹层

文件：`内容类型筛选-方案C类型多选弹层-261115-v0.1.0.html`

- 工具栏只占一行：内容类型按钮（带已选数量徽标）＋搜索＋来源胶囊；点按钮弹出面板，按组勾选（组头可全选/半选），底部「清除全部 / 完成」。
- 已选类型以胶囊回显在第二行，可单个 × 掉或整体清空。
- 优点：列表区最大，适合以列表为主、偶尔筛类型的用法；类型维度可自由组合。
- 缺点：类型要进弹层才看得见，多一层操作。

## 共同部分（三份一致）

- 同一份 14 条示例数据，覆盖 5 种纯文字稿、5 种图文稿、3 张图片，便于直接对比。
- 列表行样式一致：标题 + 「来源 · 时间」小字；右侧类型标签（大类 + 文章类型 + 具体稿型）；最右是字数或图片尺寸。
- 都带搜索（标题关键词）、来源筛选、空态提示、当前筛选回显。

## 自检

- 三份均：file:// 打开无控制台错误、无外部请求、无横向溢出、默认 14 项全显示。
- 方案 A：选「图文稿」→ 8→5 项（自动切到文章大类）；再点「合并图文稿」→ 1 项；切「图片」→ 3 项。
- 方案 B：点「合并稿」→ 1 项，路径显示「文章 › 纯文字稿 › 合并稿」；点「图片」→ 3 项。
- 方案 C：弹层勾「图文稿」组 → 5 项、徽标 5、回显 5 个胶囊；点「完成」弹层收起；× 掉一个 → 4 项。
