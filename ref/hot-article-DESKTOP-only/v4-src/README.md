## 设计变化

| 项目 | Windows 版规则 |
| --- | --- |
| 字体 | 优先 Microsoft YaHei UI，缺失时 Noto Sans SC；正文 16px，辅助 14px，区块标题 20px，页面标题 28px |
| 控件 | 按钮和输入框 40px，单选/复选视觉 18px、选择行至少 40px；焦点使用 2px 蓝色描边 |
| 导航 | 宿主导航保留；六步在顶部切换，仅当前工作区滚动，避免数千像素的整页长卷 |
| 操作 | 第一至四步不显示底部操作栏；第五、六步保留固定操作栏，当前稿导出、生成图文稿、合并无需滚动寻找 |
| 风格库 | 全宽卡片内展示完整说明、标签、对话对象与核心抓手；保留常用、使用次数与排序信息 |
| 生成设置 | 原标题、立意和完整风格组成紧凑快照；方向横排，篇幅设置独立；支持 1–3 稿 |
| 稿件处理 | 切换稿件方向、各稿独立选标题；批量导出位于标签行右侧，预览可折叠 |
| 异常处理 | 单稿、双稿、部分失败、续跑、生成中和合并中分别提供状态稿；仅完整三稿显示合并操作 |
| 导出和交接 | 格式及目录选择；默认系统桌面、目录记忆；图文只交接当前稿，先保存再交接，由用户手动开始 |

窗口基准 1440×1000，另有 1280×800 最小窗口稿。尺寸均为逻辑像素；16px 对应 96 DPI 下的 12pt。生产落地应使用 Tk 的系统缩放与字体换算，不能把 Figma 的 px 数字直接当成 Tk 的 point。125%/150% 系统缩放、中文输入法、系统文件夹选择器及原生标题栏仍需实际 Windows GUI 验收。本地浏览器预览会缩放整张画布，其视觉字号不能作为原生字体大小的测量依据。

窗口顶部的“最小化、最大化、关闭”表示系统标题栏位置；生产版使用系统窗口控件，不把这些文字作为自绘标题栏实现。

## 本地预览

在项目根目录执行：

```powershell
python -m http.server 8876 --bind 127.0.0.1 --directory design/hot-article-windows
```

打开 <http://127.0.0.1:8876/>。顶部评审工具栏已移除，六步主页面使用工作区内部导航切换。特殊状态可使用 URL 参数查看，例如 `?scene=single5`（单稿）、`?scene=partial5`（部分成功）、`?scene=compact4`（最小窗口）、`?scene=foundations`（控件规范）。

本地预览的榜单数量默认为 10 条，默认结果列表和数量标记一致；最多提供 10 条明确标注为原型的示例数据，修改获取数量后点击获取会更新列表。清空后可以重新获取。这些预览调整位于 `index.html`，不修改 Figma 生成脚本和插件包。

第一步移除底部“已选原标题 / 继续提炼立意”操作栏。点击任意榜单行或单选控件后，保存唯一选题并直接进入第二步“核心立意”；再次点击当前已选行也会进入第二步，返回榜单仍保留选择。

选题跳转时先显示 160ms 的行高亮确认，再用 240ms 的淡入与轻微上移动画呈现第二步工作区，导航和侧栏保持稳定。过渡期间防止重复选择；手动切换步骤会取消待执行跳转。系统开启“减少动画”时立即切换，不播放动画；进入后焦点定位到第二步标题。

榜单结果移除右侧详情卡片，表格占满内容宽度。列顺序为：选择、排名、榜单原标题、分类、热门值、采集时间、平台。标题最多两行，悬停显示全文；分类悬停显示完整标签，缺失显示“待分类”；热门值支持千分位和万单位，保留零值；时间统一展示北京时间。当前选题在步骤切换间保留，下游原标题同步显示当前选择。所有新增数据仅为展示示例，不表示真实采集结果。

表格最小逻辑宽度为 960px，空间不足时只在表格内横向滚动，表头随表格纵向滚动固定。可通过 `?scene=step1&width=1280` 查看 1280×800 的榜单布局，`?scene=step1` 为 1440×1000 布局。

第二步标题下补充操作说明，提示查看论证思路与关联、选中后进入写作风格设置。移除右侧立意详情区，核心立意列表占满内容宽度。卡片使用白色说明区、18px 主观点与柔和绿边，选中项主观点区域为浅青绿底，辅助内容保持白底，仅当前选项显示“当前选用”，不展示立意编号。每条卡片下方始终展开论证思路与原标题关联，两栏展示，正文 16px；不提供折叠操作行。点击核心立意主观点区域或单选按钮后自动进入第三步，重复点击当前选项同样跳转；原生单选支持键盘切换。进入第三步后定位到顶部标题，保留已选写作风格；从第四步“重新设定”进入时，选好立意仍返回原设置页。三条论证与关联内容为原型示例。顶部分类标签紧随原标题，长标题时可换行；移除“重选原标题”，将生成条数与“获取核心立意”合并到原标题卡片右侧，空间不足时换行。第二步不显示底部选择提示及“上一步 / 继续选择写作风格”操作栏，可通过顶部步骤导航切换步骤。该调整仅在 `index.html` 的预览适配层实现，不改 Figma 生成源或生产业务。

第三步在获取设置上方显示当前榜单原标题及分类，移除右侧风格详情与底部选择提示、上一步和继续操作栏。风格列表占满宽度，每张卡片独立展示名称、使用次数、常用入口、完整写作风格、核心标签、对话对象和风格优点 / 核心抓手，内容始终展开；选中状态仅通过单选按钮、浅色标题栏与绿色侧边提示展示，不额外显示“当前选用”标签。常用数量及最多五个的说明置于列表标题行，紧跟结果条数。风格卡片使用独立的名称操作栏：左侧单选与名称，右侧使用次数及常用入口；内容区左侧展示完整风格描述与标签，右侧浅灰绿提示区分组展示对话对象及核心抓手；该提示区在原比例布局基础上加宽 20 个逻辑像素，左侧同步收窄，保持卡片总宽和栏间距不变。选中项使用浅青绿标题栏与绿色侧边提示，正文 16px、风格名称 18px。切换风格保留列表滚动位置，仍可通过顶部导航进入第四步；从第四步重新设定风格时返回原页。各条描述、标签及使用次数均为预览示例。

预览支持方向勾选、每稿独立选标题、预览展开/收起、导出格式及目录记忆、图文交接顺序。目录保存在预览专用的 localStorage `windows-design-export-dir`，不会修改应用的实际导出目录。目录输入用于验证记忆效果；生产版应调用系统文件夹选择器。

“查看生成结果”是状态演示入口，不代表模型已经执行。没有实际导出、合并、文件保存、任务恢复或图文生成；历史任务、来源、常用设置等入口仅解释设计意图。

## 步骤跳转动效（已采用 A + B 组合）

本地原型默认使用组合动效：内容以 18px 横向位移及淡入在 280ms 内进入；第二、三步的“榜单原标题＋分类”区域，以及第四步包含原标题、核心立意、风格名称和说明的“创作输入快照”卡片内部的完整信息区，在入场结束后以 700ms 为一周期柔和闪烁三次（仅背景明暗变化，不带外圈、阴影或边框，文字始终可读；外层卡片静态样式不参与闪烁），完成后恢复。第一至五步均不单独高亮页面主标题；第六步保留标题延后 200ms 柔和亮起、800ms 恢复的效果。前进由右向左进入，返回反向进入；首次加载及同一步骤内状态更新不重复播放。所有步骤切换共用此效果，快速切换会取消前次动画。遵循 `prefers-reduced-motion`，减少动态效果时不播放动画并定位标题。所有页面跳转均直接进入目标步骤，不依次展示中间步骤，例如 1 → 5、2 → 5、4 → 1 都只播放目标页面的入场动效。保留选题、立意、风格和各稿标题；第六步仍需三稿全部完成后才可进入。

打开 `http://127.0.0.1:8876/motion-preview.html` 可播放全部五段衔接，默认展示已采用的组合方案，原 A/B/C 保留供回看。`step-motion.js` 默认使用 `combined`，明确传入 `?motion=slide|focus|relay` 可对比单独方案；不保存用户最终偏好到浏览器存储。

对比页通过同源、指定父窗口且仅 `motionPreview=1` 可用的消息入口重播示例状态；不调用模型、不执行真实任务。本次仅更新本地原型，未改动生产 GUI 或 Figma。
