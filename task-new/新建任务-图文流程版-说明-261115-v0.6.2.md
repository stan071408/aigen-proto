# AIGenPlatform 新建定时任务 · 图文流程版 · v0.6.2

- 日期：2026-11-15（北京时间，文件名日期 261115）
- 基于：v0.6.1（旧版不覆盖）
- 范围：按项总 3 条反馈改三稿选择、深度加工结果区、图文生成标题。

## 相对 v0.6.1

1. **三稿选择逻辑**：
   - 「生成三稿」关闭时，下方出现三张稿型卡：差异化稿 / 广度稿 / 深度稿，默认三张全选；
   - 每张卡下方有「每稿字数」两个输入（默认 1000–1200 字）；
   - 只有三张都勾选时，才显示「三稿合稿」开关；取消任意一张，合稿开关和引导里的 3.4 都隐藏；
   - 重新勾回三张，合稿开关重新出现（默认关，需手动打开）。
2. **深度加工页去掉「三稿 / 合稿」结果占位区**（图三区域不再显示）。
3. **图文生成页「本次产出」标题改为「待生成文章」**，右侧仍显示 N 篇。

## 自检

- 「生成三稿」开：无稿型卡，显示合稿开关；结果区不存在。
- 关闭：三张稿型卡全选、每稿字数 1000–1200、合稿开关显示；取消一张后合稿开关与 3.4 隐藏；重新全选后合稿开关恢复（默认关）。
- 图文生成页标题为「待生成文章」。
- 无控制台报错、无外部请求、无横向溢出。
