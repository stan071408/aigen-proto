# AIGenPlatform 新建定时任务 · 图文流程版 · v0.8.0

- 日期：2026-11-15（北京时间，文件名日期 261115）
- 基于：v0.7.3（旧版不覆盖）
- 范围：按项总 5 条反馈改合稿口径，重排三处卡片，统一待生成文章行样式。

## 相对 v0.7.3

1. **三稿合稿开启 = 只出合并稿**：开启后不再分别保留原稿/三稿的图文稿，进入图文生成只产出「合并图文稿」，每篇文章 1 篇，共 5 篇。关闭合稿时按三稿各出图文稿（3 篇/篇）；三稿也关时按勾选稿型各出（原稿图文稿兜底）。汇总「类型」行同步。
2. **图文生成卡片重新设计**（图二）：两行式——「封面 + 配图」（右：配图张数 + 输入 + 张）、「文章类别」（右：共 N 篇，下方类别胶囊），行间虚线分隔。
3. **待生成文章行改成图三风格**（图四红框）：单行显示，蓝色序号圆 + 标题 + 右侧蓝色「图文稿 ×N · 6 张图」，去掉第二行「类型：…」。
4. **深度加工卡片重新设计**（图五）：改成行式——核心立意（说明内联）、写作风格（右侧输入 260px）、生成三稿（右侧开关）、（三稿关时）差异化/广度/深度三行右侧勾选 + 每稿字数两个数字框、三稿合稿（右侧开关）。
5. **原稿设定卡片重新设计**（图六）：行式——本次将生成（右：N 篇原稿）、文章标题（胶囊，换行占满）、去 AI 化（右侧开关）。

## 统一后的卡片规则

- 一张设置卡内：左「标题 + 小字说明」，右控件/数值；行与行之间虚线分隔。
- 不再用嵌套小卡片（原来 switch-row / coverrow / draft 卡都收进行内）。

## 自检

- 合稿开：类别 1 个（合并图文稿），共 5 篇，行内「图文稿 ×1」；汇总类型 = 原稿 · 合并稿 · 合并图文稿。
- 合稿关 + 三稿开：类别 3 个，共 15 篇；合稿关 + 三稿关（三稿型全勾）：类别 3 个。
- 待生成文章单行、无第二行类型；三处卡片均为行式；无控制台报错、无外部请求、无横向溢出。

## 需要确认

第 1 条按「合稿开 → 只保留合并稿一条链路」实现。如果您的意思是「合稿开时三稿仍保留、只是图文稿只取合并稿」，我再调。
