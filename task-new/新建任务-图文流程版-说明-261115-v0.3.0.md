# AIGenPlatform 新建定时任务 · 图文流程版 · v0.3.0

- 日期：2026-11-15（北京时间，文件名日期 261115）
- 基于：v0.2.0（旧版不覆盖）
- 范围：按项总对定时任务第一步的说明重做第 1 步「标题设定」，并把第 2 步改名为「原稿设定」。

## 这一版的核心变化

定时任务只在设置时确认标题与参数，后续步骤由后台按周期触发；图文生成则是每一步都实时执行。页面按这个区别做了调整：

- 第 1 步不再叫「确认文章标题」，改为「标题设定」；
- 第 2 步不再叫「生成原稿」，改为「原稿设定」；
- 第 2 步显示本次要生成几篇原稿，不再假装现在生成；
- 第 3–6 步仍按图文生成的结构，但只展示固定参数与后台动作。

## 第 1 步「标题设定」的三种来源

1. **主题生成**：填想写的主题 → 按固定「生成标题数」获取候选标题 → 候选可多选或全选 → 进入第 2 步。
2. **热榜生成**，两种模式：
   - 按主题方向：填热榜主题方向 → 按「生成标题数」获取候选 → 多选/全选 → 第 2 步；
   - 按榜单排名：填排名号（如 `1,5,14`）→ 按这些名次获取榜单原标题，每个排名一条候选 → 多选/全选 → 第 2 步。
3. **自定标题**：填好标题后直接进入第 2 步，没有候选列表。

候选默认全部勾选，可单条取消，也可「全选 / 取消全选」；右上角实时显示「已选 N / M 篇」。勾选几条，本次任务就生成几篇，后续原稿、三稿、图文稿、导出都按这个篇数走。

## 页面结构

- 右侧步骤引导：01 标题设定 / 02 原稿设定 / 03 深度加工（可选，3.1–3.4）/ 04 图文生成 / 05 导出 / 06 执行周期。
- 左侧画布：第 1 步设置卡 + 候选标题结果区；第 2 步显示本次生成篇数与标题清单；第 3–4 步固定参数；第 5 步导出格式多选（默认 Word）；第 6 步执行周期 + 汇总。
- 底部上一步 / 下一步固定在视口底部，候选多时不用滚到底才能点下一步。

## 需要确认

1. 「生成标题数 5 个」是固定值，还是用户可改？目前按固定 5 处理。
2. 热榜「按榜单排名」获取的标题是否也要允许取消勾选？目前允许，默认全选。
3. 自定标题现在只支持一条；要不要支持多行/多条？
4. 勾选多篇时，是每篇都走完整流程（原稿 → 三稿 → 合稿 → 图文稿 → 导出），还是只取其中部分步骤？目前按每篇都走完整流程。
5. 第 1 步还没有接真实榜单数据，候选为示例；「获取候选标题」是模拟动作。
