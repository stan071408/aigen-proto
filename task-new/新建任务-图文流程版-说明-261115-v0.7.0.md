# AIGenPlatform 新建定时任务 · 图文流程版 · v0.7.0

- 日期：2026-11-15（北京时间，文件名日期 261115）
- 基于：v0.6.2（旧版不覆盖）
- 范围：按项总 4 条反馈增加文章类型、调整封面配图行。

## 相对 v0.6.2

1. **执行周期汇总增加「类型」行**：按当前设置列出本次会产出的类型——
   - 原稿；
   - 三稿（差异化、广度、深度）（按实际勾选的稿型显示）；
   - 合并稿（开了合稿才显示）；
   - 原稿图文稿；
   - 差异化 / 广度 / 深度图文稿；
   - 合并图文稿（开了合稿才显示）。
   多个类型用胶囊分行展示，不挤在一行。
2. **封面 + 配图改一行**：标题「封面 + 配图」加粗放大到 15px，说明文字与标题同一行；不再上下两行。
3. **右侧标签改成「配图张数」**，后面是 1–6 的数字输入和「张」。
4. **图文生成页「待生成文章」每篇下面增加一行类型**：如「类型：原稿 · 三稿 · 合并稿 · 图文稿」，随设置变化。

## 自检

- 汇总「类型」行默认显示 8 个胶囊：原稿、三稿（差异化、广度、深度）、合并稿、原稿图文稿、差异化图文稿、广度图文稿、深度图文稿、合并图文稿。
- 关合稿后「合并稿」「合并图文稿」消失；关三稿后按勾选稿型显示。
- 封面 + 配图一行、标题 15px 加粗，标签为「配图张数」。
- 待生成文章每行有类型说明。
- 无控制台报错、无外部请求、无横向溢出。
