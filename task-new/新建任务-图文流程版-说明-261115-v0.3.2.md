# AIGenPlatform 新建定时任务 · 图文流程版 · v0.3.2

- 日期：2026-11-15（北京时间，文件名日期 261115）
- 基于：v0.3.1（旧版不覆盖）
- 范围：按项总 4 条文案 / 布局反馈改第 1 步热榜部分。

## 相对 v0.3.1

1. **榜单排名号 placeholder 改为**：「例如：1,5,14；那么按榜单第 1、5、14 名取原标题；填几个排名就生成几条候选。」
2. **榜单排名号下方的说明改为您给的长文案**：「按“主题方向”匹配榜单原标题（今日数据），找到关联的榜单原标题根据指定排名生成；也可以不指定主题方向，那么获取所有榜单标题数据，然后根据指定“榜单排名号”生成。你也可以指定“主题方向”匹配榜单标题（今日数据），选定匹配榜单标题生成（“榜单排名号”就无效了）。」
3. **去掉热榜主题方向输入框下面的那句提示**（「按主题方向匹配今日榜单原标题；不填则用下面的榜单排名号。」）。
4. **热榜主题方向输入框和「获取候选标题」按钮放同一行**（按图四），并取消原来排名号下方那个独立的「获取候选标题」按钮。

## 现在热榜来源的布局

- 热榜主题方向（可空）+ 生成标题数（固定 5）+ 同行「获取候选标题」；
- 下方：榜单排名号输入框 + 长说明；
- 填了主题方向时，排名号仍置灰、不生效；不填方向则排名号可用；都不填则取今日全部榜单标题。

行为逻辑与 v0.3.1 一致，只改了文案和摆放。

## 自检

- Chrome + file://，1366×900：热榜来源下只有一个「获取候选标题」按钮，且与主题方向输入框同一行（y 坐标一致）。
- 方向输入框下的旧提示已移除；排名号 placeholder 与说明已换成新文案。
- 填方向后排名号 disabled；清空方向后恢复；获取候选/多选/全选、六步保存均正常；无控制台报错、无外部请求、无横向溢出。
