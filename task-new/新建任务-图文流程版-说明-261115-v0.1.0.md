# AIGenPlatform 新建定时任务 · 图文流程版 · v0.1.0

- 日期：2026-11-15（北京时间，文件名日期 261115）
- 范围：按项总反馈，放弃前三套向导式方案，改成照搬「图文生成」页面的步骤设计，做一个新建定时任务页。
- 关系：这是第 4 版方向；前三套（方案 A/B/C）保留在 `task-new/` 里作历史，不再作为主推。

## 页面结构（照搬图文生成）

- 左侧是大画布：顶部「定时任务 · 新建」眉题 + 大标题，下面按「第 N 步」展示当前步骤；每一步有设置卡、日志行、结果/预览占位区。
- 右侧是「步骤引导」：01 确认文章标题、02 生成原稿、03 深度加工（可选）含 3.1 核心立意 / 3.2 写作风格 / 3.3 生成三稿 / 3.4 三稿合稿、04 图文生成、05 执行周期。当前步骤高亮，已完成打勾，不可提前点。
- 底部：上一步 / 下一步，最后一步「保存并启用」。
- 固定参数用「锁定行」显示：左侧小锁、参数名与说明、右侧值 +「固定」标签，不可编辑。

## 当前固定参数（先按图文生成默认值锁定，等项总敲定）

| 参数 | 当前值 |
| --- | --- |
| 生成标题数 | 5 个 |
| 去 AI 化 | 开 |
| 核心立意 | 3 条 |
| 写作风格 | 清晰克制 |
| 生成三稿 | 固定生成 |
| 三稿合稿 | 固定生成合并稿 |
| 生图方式 | 豆包 |
| 封面 + 配图 | 1 张 + 5 张 |
| 导出格式 | Word（.docx），同时写入内容库 |

可编辑的只有：标题来源（主题生成 / 热榜生成 / 自定标题）、主题或指定标题、示例候选标题、执行周期（单次 / 每天 / 每周 / 自定义 + 时刻）。

## 五个步骤的内容

1. **确认文章标题**：来源分段控件、主题输入、生成标题数（锁定 5 个）、候选标题示例（可选一条）。定时执行时按来源重新生成，默认取第 1 条。
2. **生成原稿**：显示本篇标题，去 AI 化锁定为开；结果区留原稿预览占位。
3. **深度加工（可选）**：3.1–3.4 四项固定参数锁定；结果区留三稿/合稿占位。
4. **图文生成**：生图方式、封面+配图、导出格式三项锁定；结果区留图文稿占位。
5. **执行周期**：周期与时刻可编辑；下面汇总任务、流程、固定参数、导出、周期。

## 需要项总敲定 / 确认

1. 上面表格里的固定参数值对不对？请直接给准确值或增删。
2. 是不是所有定时任务都走「三稿 → 合稿 → 图文稿」完整流程？如果有任务只出原稿、或只出图文稿、或只出三稿不合并，请告诉我哪些步骤可以关掉（我可以做成固定参数里的开关，或按任务类型裁剪步骤）。
3. 导出是否固定 Word？要不要支持 Markdown / 不导出？
4. 热榜来源的标题数是否也用 5 个，还是沿用 8 个？
5. 导出这次没有单独做成一个步骤（图文生成里导出是结果区操作）；现在是作为固定参数放在第 4 步和汇总里。如果您要单独的「导出」步骤，我再加。
