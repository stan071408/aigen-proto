# AIGenPlatform 新建定时任务 · 图文流程版 · v0.2.0

- 日期：2026-11-15（北京时间，文件名日期 261115）
- 基于：v0.1.0（旧版不覆盖）
- 范围：按项总反馈更新：① 新增「导出」步骤，格式由用户在任务设置时选择，默认 Word；② 步骤仍是一步一步走；③ 固定值/设置值按步骤列清，等您逐步核对。

## 相对 v0.1.0

1. **新增第 5 步「导出」**，步骤变为 01 确认文章标题 / 02 生成原稿 / 03 深度加工（可选）/ 04 图文生成 / 05 导出 / 06 执行周期。
2. 导出格式改为用户多选：Word（.docx）默认勾选，可再加 Markdown（.md）；至少保留一种。导出不再作为固定参数。
3. 第 4 步只保留「生图方式、封面+配图」两项固定参数；「同时写入内容库」仍是固定动作。
4. 右侧引导提示改为：带锁的是固定参数，来源/主题、导出格式、执行周期可设置。

## 每一步的固定值 / 设置值（请逐步核对）

| 步骤 | 可设置 | 固定值（当前） |
| --- | --- | --- |
| 01 确认文章标题 | 来源、主题/指定标题、示例候选标题 | 生成标题数 5 个 |
| 02 生成原稿 | — | 去 AI 化：开 |
| 03 深度加工（可选） | — | 核心立意 3 条、写作风格 清晰克制、生成三稿、三稿合稿 |
| 04 图文生成 | — | 生图方式 豆包、封面 1 + 配图 5、写入内容库 |
| 05 导出 | 格式多选：Word（默认）/ Markdown | — |
| 06 执行周期 | 单次/每天/每周/自定义 + 时刻 | — |

固定值目前都是图文生成里的默认值，等您一步步给准确值或增删。改一个我改一个，不一次猜。

## 流程假设

- 当前页面按最完整流程走：原稿 → 三稿 → 合稿 → 合并稿图文稿 → 导出。若某类任务只出原稿、只出图文稿、或三稿不合并，请在该步告诉我要不要裁掉后续步骤。
- 定时执行时按来源重新生成标题，默认取第 1 条；第 1 步候选标题只作示例。

- 六步可走通，「保存并启用」有提示；导出默认 Word，勾 Markdown 后第 6 步汇总同步显示两种格式。
