## 三套方案一句话

| 方案 | 一句话 | 适合 |
| --- | --- | --- |
| A 分步向导 | 顶部横向步骤条，一次只配置一步，底部上一步/下一步 | 最稳妥，学习成本最低，和现有抽屉习惯接近 |

## 共通流程模型（三套一致）

基础：选择标题 → 生成原稿 →（按需）图文稿 / 三稿 → 导出 → 执行周期。

| 产出 | 流程 |
| --- | --- |
| 原稿 | 选择标题 → 生成原稿 → 导出文稿 |
| 图文稿 | 选择标题 → 生成原稿 → 生成图文稿 → 导出图文稿 |
| 三稿（单/全） | 选择标题 → 生成原稿 → 三稿生成 → 单稿/全稿导出 |
| 三稿图文稿 | 选择标题 → 生成原稿 → 三稿生成 → 三稿单稿图文稿 → 导出 |
| 合并稿 | 选择标题 → 生成原稿 → 三稿生成 → 合并成合并稿 → 导出 |
| 合并稿图文稿 | 选择标题 → 生成原稿 → 三稿生成 → 合并成合并稿 → 合并稿生成图文稿 → 导出 |

- 定时任务最后统一多一步「执行周期」（单次 / 每天 / 每周 / 自定义 + 时刻）。
- 沿用 v0.14.10 的控件：来源分段控件主色实心选中、生成标题数在标签行右侧、输入框整行；不设任务名称。
- 步骤/选项的默认值：主题生成、三国野史、生成标题数 5、去 AI 化开、三稿合并并生成图文稿（A/B 默认展示最完整流程）。

## 三套方案细节

### A 分步向导
- 顶部 6 个步骤卡（选择标题 / 生成原稿 / 加工方式 / 三稿处理 / 导出 / 执行周期），随分支自动增减；完成的打勾。
- 中间单步表单，底部固定「上一步 / 下一步」，最后一步「保存并启用」。
- 加工方式用 3 张卡（只原稿 / 图文稿 / 三稿）；三稿处理再用 3 张卡（直出、单稿图文稿、合并稿）。

### B 工作台预览
- 左栏纵向步骤（含说明、完成状态），中间表单，右栏常驻「执行流程」：环节链、本篇标题、产出、导出、周期。
- 底部按钮在中间栏；右侧实时反映选择，适合边配边看结果。

### C 流程模板
- 首屏 6 张流程卡，直接对应上面 6 条流程；选定后顶部显示已选流程，可「换流程」。
- 下方纵向步骤清单：当前步骤展开配置，已完成步骤折叠成摘要（可点开改），未到步骤置灰。
- 好处是用户先明确最终产出，再填配置；不会在分支里迷路。

## 假设 / 需要项总确认

1. **「导出」作为独立一步**：图文生成流程里的导出，在定时任务里我理解为「导出格式 + 是否写入内容库」的配置步骤；如果您希望导出只作为流程终点、不单独配置，我可以把它并进执行周期。
2. **定时任务如何选标题**：定时执行时无法人工点候选标题，原型里第 1 步的候选标题只作示例预览，实际执行按来源重新生成、默认取第 1 条。如果要做「运行时人工确认」需要另加暂停/确认机制，本次没做。
3. **三稿处理组合**：目前提供「直出（单/全稿）、单稿图文稿、合并稿（可再生成图文稿）」三种，覆盖您列的 4 条三稿流程；没有做「三稿同时直出 + 合并」这种并行多产出。
4. **示例数据**：标题、周期、格式均为示例；保存只弹提示，不写回任务中心列表（这是选稿页，不接主原型）。
