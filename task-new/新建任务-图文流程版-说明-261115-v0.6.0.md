# AIGenPlatform 新建定时任务 · 图文流程版 · v0.6.0

- 日期：2026-11-15（北京时间，文件名日期 261115）
- 基于：v0.5.1（旧版不覆盖）
- 范围：按项总 3 条反馈改标题数、合并导出到执行周期步骤。

## 相对 v0.5.1

1. **生成标题数可手动指定 1–10**：去掉「固定」，改成数字输入；默认 5。
2. **候选条数对齐生成标题数**：主题生成、热榜按方向匹配、热榜不填方向也不填排名时，都按当前生成标题数取候选；热榜按排名时条数 = 排名个数。数了默认 5 就是 5 条，不再出现 8 条。
3. **导出合并进执行周期，取消独立的「导出」步骤**：
   - 步骤只剩 5 步：标题设定 → 原稿设定 → 深度加工 → 图文生成 → 执行周期；
   - 执行周期页最上面是导出格式（Word / Markdown）**一行两个卡片**，下面是「本次产出」勾选文章，再下面是周期与时刻；
   - 第 2 步去掉「导出本稿」，改成「开始定时执行」；第 3 步的「导出三稿」也换成「开始定时执行」，点它直接进入执行周期页；
   - 第 4 步按钮改为「下一步：执行周期」；执行周期页底部「保存并启用」。

## 自检

- 步骤引导显示 5 步；标题数输入 1–10、默认 5。
- 改成 3 后获取候选得 3 条（主题/热榜都验证）；默认 5 条不再出 8 条。
- 执行周期页：导出格式两个卡片同一行（flex），下方本次产出可勾选，周期/时刻正常；无独立导出步骤。
- 第 2/3 步「开始定时执行」跳到执行周期；保存正常；无报错、无外部请求、无横向溢出。
