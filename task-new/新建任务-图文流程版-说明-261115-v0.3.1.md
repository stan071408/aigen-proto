# AIGenPlatform 新建定时任务 · 图文流程版 · v0.3.1

- 日期：2026-11-15（北京时间，文件名日期 261115）
- 基于：v0.3.0（旧版不覆盖）
- 范围：按项总 4 条反馈改第 1 步「标题设定」。

## 相对 v0.3.0

1. **「获取候选标题」按钮移到输入框同一行**，样式按图二（输入框占满剩余宽度 + 右侧主色按钮）；主题生成和热榜主题方向都按这个排。
2. **榜单排名号移到热榜主题方向下面**（图三红框下方），不再是一个独立模式。
3. **去掉「热榜模式」分段控件**（图五红框），热榜不再先选模式，直接填方向 / 排名即可。
4. **热榜获取逻辑按项总说明改：**
   - 填了「热榜主题方向」：按方向匹配今日榜单原标题，返回最多 5 条候选，可多选 / 全选；此时「榜单排名号」置灰、不生效（提示「已按主题方向匹配，榜单排名号不生效」）。
   - 不填方向、填了「榜单排名号」（如 `1,5,14`）：取今日全部榜单标题，再按这些名次生成候选，每个排名一条。
   - 不填方向、也不填排名：获取今日全部榜单标题（示例 8 条），全部作为候选，可多选 / 全选。

## 现在的第 1 步结构

- 来源：主题生成 / 热榜生成 / 自定标题。
- **主题生成**：想写的主题 + 生成标题数（固定 5）+ 同行「获取候选标题」→ 5 条候选，多选 / 全选。
- **热榜生成**：
  - 热榜主题方向（可空）+ 生成标题数（固定 5）；
  - 榜单排名号（方向为空时可用）；
  - 「获取候选标题」按钮在排名号下面。
- **自定标题**：只填标题，直接进第 2 步。

候选默认全选，右上角显示「已选 N / M 篇」，勾几条本次任务就生成几篇。

## 需要确认

1. 填了主题方向后，排名号目前直接置灰不生效；您原话里也提到「找到关联的榜单原标题根据指定排名生成」，如果您要的是「在匹配到的标题里再按排名挑」，告诉我，我改成：方向 + 排名 → 匹配结果按排名筛。
2. 不填方向也不填排名时，我把今日全部榜单标题都作为候选（示例 8 条）；如果应该强制填排名，我改成必填。
3. 生成标题数 5 个仍是固定值；方向匹配时最多取 5 条。

## 自检

- Chrome + file://，1366×768 / 1366×900：无控制台报错、无外部请求、无横向溢出。
- 主题生成：按钮与输入框同一行（y 坐标一致），获取 5 条候选。
- 热榜：不再有「热榜模式」；方向在上、排名在下；填方向后排名输入框 disabled 且提示不生效；方向匹配返回 5 条「今日榜单 · 匹配」；清空方向后排名恢复可用；填 `1,5,14` 返回 3 条带名次候选；都不填返回 8 条。
- 六步可走通并保存。
