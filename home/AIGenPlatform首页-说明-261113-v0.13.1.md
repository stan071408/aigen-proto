## 项总 t134 图一：v0.12.10 二级胶囊为何「看起来没生效」

在当前 v0.13.0 源码（及 v0.12.10 起的历次文件）里核对并实测（Chrome `file://` 1366×768）：

- 内容库二级来源的 DOM 已是 `<button class="hot-plat">`，放在 `.lib-row-sub` 浅底缩进行内。
- 计算样式已是规范值：高度 26px、字号 11px、1px `#cfd8e6` 描边、圆角 999px；选中为 `#e3edfc` 浅蓝底、深色字 `#14213a`，不是实心蓝。
- `#pageHost .lib-srcs .hot-plat` / `#pageHost .hot-plat` 选择器有效，后面没有更高优先级或 `!important` 把它们盖回 36px / 2px / 蓝实心。列表视图与卡片视图共用同一套筛选栏，不存在「某个视图仍用旧按钮」的分支。

项总 t134 图一里的二级（粗 2px 描边、约 36px、选中蓝实心大按钮）是 **v0.12.9 及更早** 的样子：当时一级「文章 / 短视频」和二级「全部 / 原稿 / …」用了同一档大按钮。v0.12.10 已改样式，但图一与现行 v0.12.10–v0.13.0 计算样式不符。

**根因：** 不是 v0.13.0 里 CSS 被覆盖或某视图漏改，而是截图对应的仍是改前样式（未刷新的旧标签页、旧附件，或当时打开的仍是 v0.12.9 文件）。本版把层级规则写进说明，并在内容库、任务中心等一级+二级并存处再核对一遍，保证打开 v0.13.1 时就是「一级大、二级小」。

## 层级区分规则（全站统一）

- **一级：** 蓝实心填充大按钮（`.lib-pill`）：高度 40px、字号 14px、字重 600、圆角 12px、2px `#1c5fc4` 边、选中/当前 `#1c5fc4` 底白字。
- **二级：** 复用热榜采集平台 `.hot-plat`：高度 26px、字号 11–12px、字重 400、1px `#cfd8e6` 描边、圆角 999px；选中 `#e3edfc` 浅蓝底、深色字（不是蓝字、不是实心蓝）。视觉上明显小一档、轻一档。
- 二级行使用浅底 `#eef3f9` + 左缩进（`.lib-row-sub`），表示从属于上方一级。

## 预览默认折叠（t135 图一）

内容库文章详情抽屉：

- 打开时「正文预览」条默认折叠；条固定在抽屉正文区底部，上方信息行和配图可内滚。
- 点击展开后，上方信息行、拒图说明、配图区全部收起；预览区 `flex:1` 撑满抽屉正文高度，正文在预览区内滚动。头部标题栏和底部「复制正文 / 发布排期」按钮始终保留。
- 再点折叠，上方区域恢复。

任务中心监控里点产出会打开同一内容库文章抽屉，行为一致。任务中心「看日志」是居中日志弹窗，没有折叠预览，不套用此交互。首页旧任务详情抽屉（`openJob`）没有文章预览折叠条，只统一了 `.kv` 标签/值，不套用撑满预览。图文生成 / 热榜画布里的 3.3 预览不在抽屉内，本版有意不改。
