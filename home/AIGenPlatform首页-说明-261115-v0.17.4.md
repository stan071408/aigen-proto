# AIGenPlatform 首页 · 方案3 能力宫格型 · v0.17.4

- 日期：2026-11-18（北京时间）
- 基于：v0.17.3（旧版不覆盖）
- 范围：修 v0.17.3 总览「首页异常」，按项总图一补齐两个面板的控件。

## 问题与修复

v0.17.3 里总览的 KPI 用了主原型不存在的 `.kpis` 类名，且新样式全部挂在 `#pageHost` 下（总览实际渲染在 `#dash`），导致 KPI 卡片没有网格、宽窄不一、面板无内边距——看起来就是“首页异常”。

本轮把 `.hm-` 前缀的样式全部去掉 `#pageHost` 作用域（类名唯一，不会污染），并补齐 KPI 卡片自身样式（白底、13px 圆角、28px 数字、四项等宽等高、可点击）。

## 按图一补齐

1. **近 7 天生成量 / 发布量**面板：加「全部 / 文章 / 图片」三段切换（可用：文章只留蓝色柱、图片只留绿色柱）、右侧「按天统计」；柱体圆角 8px，堆叠色为文章 / 图片 / 等待 / 失败，图例含「发布量：BS 端不产生，CS 端回写后再显示」。
2. **今日执行流水**面板：加「全部 / 执行中 / 失败」三段切换（失败只留失败行）、右侧「11-11 至今 N 条」；按日期分组，左侧时间轴圆点按状态着色，面板内部滚动（内容 435px > 可视 247px）。
3. 两个面板固定 330px 等高；最近产物三张 168px 封面卡；整页一屏（695 / 768 都不出纵向滚动）。
