## 对照需求逐条落实
1. **整体采用 A 布局，左侧导航可折叠（参考 C），列表跟 A 一样**
   - 左侧深蓝侧栏，分组为：总览 / 创作（图文生成、AI 热榜图文生成、短视频「即将支持」置灰）/ 管理（内容库、任务中心、发布中心、账号与额度）/ 系统（设置、系统）。
   - 点品牌旁的按钮可以折叠成图标条，悬停时显示名称。
   - 折叠状态保存在内存里，同时写入 localStorage（包在 try/catch 里，不可用时不报错）。
2. **右侧顶部有每个页面的导航（首页除外），参考 B**
   - 首页没有页内导航栏，首屏占满右侧。
   - 点「图文生成」或「AI 热榜图文生成」会进入占位页，顶部是 B 式「面包屑 + 二级标签」（图文生成 / AI 热榜图文生成 / 短视频·即将支持），二级标签可以切换。
   - 其它导航项点击后提示「该页面待讨论」。
3. **总览做成首页，用来介绍项目；风格参考 Canva AI 页，第一屏用图一样式**
   - 三个方案的首屏结构一致：深蓝渐变星空底，加几只发光水母（SVG）；顶部是营销式导航（Logo、产品 / 能力 / 流程 / 多账号 / 架构 / 安全，右侧是语言和「进入工作台」）；中间是超大白色粗标题、居中副标题和白色胶囊按钮；底部一排略带透视倾斜的产品缩略卡，露出一半左右，并缓慢横向漂移（v2 方向相反）。
   - 1366x768 和 1920x1080 下，标题和按钮都完整可见，卡片半露（已自测）。

## 三个方案的差异
| | 方案1 演示分区型 | 方案2 流程叙事型 | 方案3 能力宫格型 |
|---|---|---|---|
| 首屏标题 | 把一个热点，变成一篇好图文 | 从选题到发布，六步走完一篇图文 | 一个平台，管好创作、账号与发布 |
| 主体组织 | 大块彩色分区，左文右演示窗，演示窗内用 Tab 切换（简报画布步骤 / 热榜来源 / 全流程 / 账号额度 / 任务·内容·发布） | 深色故事区里是六步时间轴，加横向滚动卡片（可点节点或用箭头切换）；规则用可视化表现（豆包额度柱、头条串行泳道） | Bento 宫格汇总全部能力，下面依次是六段流程色带、SVG 架构图（云端控制面 ⇄ 本地执行代理）和状态 Tab |
| 适合 | 想逐个讲清功能 | 想先讲清「一篇怎么做出来」 | 想一屏看全、偏产品全景 |
| 动效 | 分区淡入 | 时间轴联动 + 横向滑动 | 宫格悬浮抬升 |

三个方案都覆盖了以下内容：
- 定位：B/S，云端控制面 + 本地执行代理，浏览器动作都在执行机上完成。
- 能力：图文生成（简报画布 8 步）、AI 热榜、短视频（即将支持）。
- 全流程：选题 → 原稿 → 深度加工 → 三稿 → 出图 → 发布。
- 豆包多账号额度规则、头条多账号串行限频规则。
- 任务中心 / 内容库 / 发布中心概览。
- 多类型 × 多平台。
- 风控停号、需人工等安全状态。
- 结尾大 CTA「进入工作台」「开始创作」。

动效遵守 prefers-reduced-motion：开启「减少动态效果」时，漂移和淡入都会关闭。

## 自测
用 Headless Chrome（Playwright）跑了 74 项检查，**全部通过**，结果见 .build/selftest-result.json。检查内容：
- 首屏标题和 CTA 在可视区内，卡片半露，无横向溢出（1366x768、1920x1080）。
- 侧栏折叠和展开。
- 所有 Tab 都能切换。
- 顶部菜单可以跳到对应锚点，六个锚点都存在。
- 方案2 的流程「下一步」按钮可用。
- 导航：内容库会弹 Toast；图文生成进入占位页并显示 B 式导航；二级标签能切到热榜；点总览能回到首页。
- 无控制台报错。
- reduced-motion 下动画关闭，所有内容直接显示。
