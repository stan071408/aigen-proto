## 相对 v0.14.7

1. **状态筛选：状态色常驻，选中只加边框。** 「全部 / 等待 / 成功 / 失败」四项默认就显示各自状态色，不再只在选中时上色：
   - 全部：白底、主色字（`#1c5fc4`）
   - 等待：米黄底 `#f4f0e6`、深棕字 `#8a6a16`
   - 成功：浅绿底 `#e3f4ea`、绿字 `#17734a`
   - 失败：浅红底 `#fde8e8`、红字 `#c42b2b`
   选中项只加 1px 边框（`#b9c9dd`）和轻投影，底色、文字色保持不变；未选中项无边框。

2. **取消「任务名称」属性（全站 BS）。**
   - 新建任务抽屉：删掉「任务名称将自动生成为：…」整行，三种来源（主题生成 / 热榜生成 / 自定标题）都不再出现；指定标题输入框 placeholder 去掉「将用作任务名称」。
   - 管理任务列表：首列由「任务名」改为「主题 / 标题」，值取该任务的主题、热榜方向或指定标题（热榜方向为空时显示「全部榜单」）。
   - 任务监控：时间轴卡片标题改为按主题 / 标题显示；搜索占位改为「搜索主题 / 标题 / 产出 / 编号」，搜索仍可命中；删除确认、立即执行提示、重试提示、执行日志标题也改用主题 / 标题。
   - 示例数据：`GEN_TASKS`、`GEN_RUNS` 中的 `name` 字段删除。
