# AIGenPlatform 首页 方案3「能力宫格型」v0.12.8 说明

基于 v0.12.7，按项总 t128u / t129u 五项修改。新文件，不覆盖旧版。时间：2026-11-13 11:47（Asia/Shanghai，UTC+8）。

## 第1条根因

3.2「写作风格数量」的「5」偏下、略偏左，是因为 `#content #step-4 #styleCount, .ctl-step input{height:36px !important}` 把输入本身撑到 36px，而规范数字框是盒子 36px（含 2px 边框）、输入 `height:auto` + `line-height:32px`，数字才能在内容区垂直居中；输入高于内容区后字形下沉，观感也偏左。

## 第5条根因

`fitViewportFill` 把撑满高度加在 `.pv-body`（或外层白卡）上，浅蓝底只画在未增高的 `.pv-empty`（min-height:160）上，所以第4步图文稿图片预览被拉高后，下方露出白底。修法是把增量交给带浅蓝底的占位体本身（外层改 flex 列，占位 `flex:1` 充满），底部圆角由外层卡 `overflow:hidden` 裁切。

## 改动

1. **数字框居中并全站对齐**：去掉第4步对输入高度的错误强制；全站 `.ctl-step-input` / `#titleCount` `#ideaCount` `#styleCount` `#hotCount` `#wordMin` `#wordMax` `#platCount` 恢复规范 `height:auto` + 32px 行高与左内边距。热榜同步。
2. **导出弹窗**：由 580px 加宽 100px 到 680px；外层 `overflow:hidden` + flex 列，仅 `#modalBody` 滚动，滚动条不再切开圆角；略收紧内边距以便 1366×768 尽量一屏放下。工作台 `dialog.modal` 同样「外层 hidden、内容区滚动」（宽度仍 460px）。
3. **3.4 合并稿与第2步原稿统一**：候选标题块移出预览卡、独立放在上方；预览卡只保留「合并稿正文预览」标题栏（类型/分类徽标 + 字数 + chevron）。候选单选项样式与原稿一致（13px、padding 10px 14px、半径 10px、gap 10px）。3.3 / 热榜 04·05 的候选标题同步为同一套样式与位置。
4. **3.3「预览文章」头改为原稿预览标题栏**：「差异化稿正文预览」（按当前稿型）+ 蓝色类型徽标 + 灰色分类徽标 + 右侧字数与 chevron；保留折叠、半高内滚动、三按钮居中。热榜 04 同步。
5. **空占位撑满不再两段色**：撑满增量给到浅蓝占位体（`.pv-empty` / `.hot-empty` / `.rf-empty` / `.empty`），整块颜色一致、底角正确。已逐项检查图文 1 / 2 / 3.1–3.4 / 4、热榜 01–05、工作台空列表。空占位约距视口底 20px、可滚动不被拉回的既有规则保持。
