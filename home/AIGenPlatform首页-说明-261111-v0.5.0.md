- 文件：`AIGenPlatform首页-方案3能力宫格型-261111-v0.5.0.html`（基于 v0.4.0 另存，旧文件未改动；单文件离线，无外链）

## 本版改动
1. 把 A 侧栏版「管理」「系统」两组共 6 个页面整体迁入方案3 工作台：内容库、任务中心、发布中心、账号与额度、设置、系统。
2. 六页的内容、交互、示例数据、子标签 / 页内分段、表格、弹窗、抽屉、待处理徽标、任务中心侧栏「3」徽标，均按 A 版带入。
3. 侧栏原占位项改为点击进入真实页面；hash 为 `#app/library` 等，经 `nav()` 跳转；折叠、选中高亮正常。
4. 样式适配方案3 工作台：顶栏面包屑为「工作台 / 管理|系统 / 页名」，不出现 A 版自带的第二套顶栏或第二套侧栏；页内组件沿用已有的晴空蓝（A 组件样式挂在 `.adash` 下）。创作页的 B 式二级标签在这六页隐藏。
5. A 版顶栏右侧的「本机运行 · 127.0.0.1 / Worker 在线 / 待处理 5 / 示例数据」放进方案3 顶栏右侧（与图文生成页同一条顶栏，不在页面里再做一套状态条）。「待处理」可点，进入任务中心并筛「等待处理」。
6. 其余页面未改版面：营销首页、登录 / 注册、总览布局、图文生成与 AI 热榜模块、短视频「即将支持」。

## 与 A 版的差异
1. 外壳是方案3 工作台，不是 A 的独立壳：有折叠按钮、用户菜单（示例用户 / 退出登录）、品牌标记仍回营销首页；面包屑带「工作台 /」前缀。
2. 路由是方案3 的 `#app/<页>` + 登录态（未登录进不了工作台），不是 A 的 `#/<页>`。页内跳转已接到 `go()` → `nav()`。
3. 「示例数据」在方案3 顶栏和页头各有一处（A 版顶栏和页头本来也各有一处，予以保留）。
4. 图文生成 / 热榜在方案3 里是嵌入简报画布的模块页。从任务中心、内容库或总览跳到这两处时，进入的是方案3 已有模块，不再是 A 版内嵌的那套简化实现。
5. 系统页 Version 里的「AIGenPlatform 0.1.0-proto」「构建时间 2026-11-11 11:40」等是 A 版示例数据，原样保留，不是本文件版本号。

## 跳转对接
