## 日期框残影：根因与修复

图一里，两个日期框上各叠着一块半透明蓝白圆角方块，盖住了「开始日期 / 结束日期」。

**根因：** 自绘日期控件把占位文字写成了 `<span class="ph">`。工作台里 `.ph` 早就被配图占位块占用，样式是 `aspect-ratio: 4/3`、`border-radius: 10px`、`position: relative`，以及背景 `linear-gradient(135deg, #cfe0fb, #eaf2ff 55%, #d7e6fd)`。日期占位文字套上这套样式后，就变成约 68×51 的渐变方块叠在 36px 高的字段上。不是隐藏的原生 `input`、不是聚焦光晕，也不是伪元素或遮罩。

**修复：** 日期占位和已选值分别改成独立类名 `agp-date-ph`、`agp-date-val`，并写明重置（去掉 aspect-ratio、渐变背景、额外内边距）。字段同时加上 `appearance: none`，避免按钮默认皮肤。修完后与控件规范 v0.3.0 的日期控件同样干净。

**规范页：** 已在 Chrome 1366×768 下检查 v0.3.0。规范里没有配图占位用的全局 `.ph`，日期字段的 `.ph` 没有渐变背景，目视也无残影，因此 **不出规范 v0.3.1**。

## 任务状态只保留三种

任务监控（`GEN_RUNS` / 定时任务执行记录）全站只保留：等待、成功、失败。去掉运行中、挂起。

具体改动：

- 状态筛选：全部 / 等待 / 成功 / 失败。
- 顶部统计卡：今日执行、成功、失败、等待（四格）。今日执行 = 当天三条状态之和。
- 日期旁统计胶囊：只显示等待 / 成功 / 失败，数量为 0 的不显示。
- 示例数据：原 R-200「运行中」改为成功（已写入内容库）；原 R-195「挂起」改为失败，去掉「生图通道不可用超 30 分钟，已挂起」和「继续」操作，日志改为执行失败。
- 立即执行、重试的示例结果改为成功，不再进入运行中；删除 `tcResume`。
- 侧栏等待角标只统计「等待」。顺带挂上 `window.ADASH`，让进入工作台后角标会按实际等待条数刷新（原先写死为 3，刷新函数因未挂到 window 而没跑到）。
- 设置、账号说明里「任务挂起到次日」改为「等到次日再执行」。工作台待处理里额度用尽的说明同步改掉，不再写「挂起」。
