## BS / CS 分工（结论摘要，供小勾出接口清单）

本原型先做 **BS 端**。发布只能走 CS 架构，相关设计从本原型移除，改由 CS 实现；BS 只保留生成、内容库和只读回写展示。

**留在 BS**

- 工作台导航与总览、图文生成画布（第 1 步标题来源「平台热榜」保留，仅去掉独立热榜导航）、内容库、任务中心（仅「定时图文生成」的任务设置与任务监控）。
- 设置：生成默认值、**API 回退每日预算**及用尽挂起规则、提示词版本只读、密钥是否已配置（掩码，不可看明文）。
- 内容库只读「发布状态」：展示 CS 回写的已发平台和文章链接（如「头条号 · 已发布 ↗」），未发布灰字「未发布」，失败显示「发布失败」。无发布/排期操作。
- 顶栏「CS 客户端：已连接 / 未连接」演示态；生图方式为「豆包（需 CS 客户端在线）」「API」。CS 未连接时豆包置灰，默认 API，并给出提示。图文生成画布与任务中心新建/编辑生成抽屉样式统一。
- 首页额度只读示例（豆包剩余张数、API 预算余），不提供账号登录或账号管理。

**移至 CS（接口与能力清单）**

1. 发布中心整页：立即发、定时发、按点位排期、发布队列、失败重试、需人工处理、排期日历、渠道能力说明。
2. 设置中的发布项：头条多账号发布规则（串行、间隔、每号每日上限、新号/风控号上限、验证码停号、登录失效跳过、UA 固定）、微信公众号发布（企业号官方接口、个人号细则）。
3. 任务中心「定时图文发布」一级分区及其新建/编辑发布抽屉、发布监控记录。
4. 内容库「发布」「发布/排期」操作按钮（卡片、列表、详情抽屉）；BS 不再发起发布，只读展示 CS 回写状态与链接。
5. 「已排期 / 发布中」过程态与排期筛选（排期在 CS）；若需在 BS 展示过程态，由 CS 另定回写字段。
6. 图文生成 / 画布上的发布入口（如有）。
7. 首页发布统计 KPI、今日发布排期/队列、待处理中的发布失败/需人工、任务详情中的 publish 类任务。
8. 营销首页中的发布中心卡、多账号串行发布、多类型×多平台发布矩阵、流程中的发布段、架构图中的发布排期等表述。
9. **豆包账号登录 / 管理**：账号池、有头浏览器登录与重登、停用/启用、各账号每日上限（含新建账号默认上限、按账号改上限）、换号与风控处理。页面「账号与额度」已从 BS 去掉。
10. 发布账号（头条 / 公众号）的登录、排序、额度与类型管理。
11. 环境变量 `WECHAT_APPID` / `WECHAT_APPSECRET` 的配置与系统自检（已从 BS 密钥表和医生检查中移除）。
12. 豆包生图的实际执行（需 CS 客户端在线）；向 BS 报告连接态。
13. 向 BS **回写**内容库发布状态：已发平台、文章链接、发布失败原因；供 BS 只读展示与「全部 / 已发布 / 未发布 / 发布失败」筛选。

**待项总确认**

- 任务监控二级分组：本版按「执行该次任务时使用的豆包生图账号」归组（等待中的记录用计划使用的账号）。生成任务没有发布账号。是否改为「任务所属账号」或其他口径，待确认。
- API 每日回退预算留在 BS 设置、豆包账号上限和登录管理在 CS，已按本次拍板执行；若要在 BS 首页继续展示豆包剩余额度，需要 CS 回写汇总数字（本原型仍用示例数据）。

## 相对 v0.13.3（项总 t139u）

### 1. 左侧导航

去掉「AI 热榜图文生成」「发布中心」「账号与额度」。原「创作」「管理」合并为「创作管理」，顺序：图文生成、短视频即将支持、内容库、任务中心。其下仍是「系统」（设置、系统）。品牌副文案改为「AI 内容生成平台」。热榜只作为图文生成第 1 步标题来源「平台热榜」保留。原指向 hot / publish / accounts 的入口（首页快捷按钮、KPI、额度卡「账号与额度 →」、营销页发布中心卡等）已去掉或改到图文生成 / 设置 / 总览；旧哈希 `#app/hot` 回退到图文生成，`#app/publish`、`#app/accounts` 回退到总览，不留死链。`enter()` 同时识别创作与管理模块，营销页「任务中心」可进入。

### 2. 发布相关设计移出 BS

发布中心页不再挂到路由；设置里的发布规则整段删除；任务中心只保留定时图文生成。一级只剩一类后，去掉「定时图文生成 / 定时图文发布」那一行，将「定时任务设置 / 任务监控」提升为顶栏一级切换（`.lib-pill`，未选为白底蓝描边，选中为蓝底白字）。内容库去掉全部「发布」「发布 / 排期」按钮。首页去掉发布失败 KPI、今日发布排期，待处理和任务中心角标不再计入发布类数量。

### 3. 任务监控树状分组表（第 1 条，已确认用在此处）

样式参照 t139-图2：深蓝一级分组行、浅蓝二级分组行、带缩进的连接线、数据行左侧缩进对齐。列与行样式参照 t139-图1 的列表气质（编号、任务名、开始时间、状态胶囊、耗时、产出、操作），**不含**渠道、发布方式、排期等发布字段。一级按日期（如「11-13 今天」），二级按执行账号（见待确认项）。分组行显示条数和成功/失败计数，可折叠/展开，默认展开。

### 4. 内容库只读发布状态

卡片、列表、详情抽屉三处同源，使用同一段只读展示：已发布为「头条号 · 已发布 ↗」（可有多个平台），点击提示将打开链接（示例，数据由 CS 回写）；未发布为灰字「未发布」；失败为「头条号 · 发布失败」。无发布操作按钮。发布状态下拉保留，选项改为「全部 / 已发布 / 未发布 / 发布失败」（去掉已排期、发布中）。原先示例里的「已排期 / 发布中」已改为「未发布」，表示尚未被 CS 回写为已发布。

### 5. 账号与额度拆分

「账号与额度」页面随导航去掉。豆包账号登录/管理、各账号每日上限列入移至 CS 清单。设置页保留「API 回退每日预算」和用尽挂起、重置时间；去掉「新建豆包账号默认每日上限」和账号换号/重登类文案。原先「在账号与额度单独设置」的指向已不存在。

### 6. 生图方式与 CS 在线态

图文生成画布（第 4 步）和任务中心新建/编辑生成抽屉，生图方式统一为两项胶囊：「豆包（需 CS 客户端在线）」「API」。工作台顶栏增加「CS 客户端：未连接」，点击可在已连接/未连接之间切换（仅演示）。未连接时豆包置灰不可选、默认 API，并显示一行小字提示。连接后可选豆包。

层级区分、标签/值区分、同功能样式统一、控件规范 v0.2.0、占位撑满到视口底约 20px 且可滚动、沙箱不用原生 form submit，均保持。
