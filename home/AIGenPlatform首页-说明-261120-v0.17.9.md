## 相对 v0.17.8

1. **任务只保留三态：** 后端与界面统一为「等待 / 成功 / 失败」。排队中、运行中、等待登录、等待额度、已阻塞在 BS 上都显示为「等待」。示例数据删掉那 9 种旧状态，`st3()` 只分三支。
2. **总览文案：** 「待执行」改名为「等待」（流水筛选与任务中心用同一个词）。KPI 改为「等待中任务数 / 到点未完成的任务」，失败卡去掉「含等待登录 / 等待额度 / 阻塞」，数字只数失败。点击等待 KPI 会进入任务中心并选中「等待」筛选。
3. **失败原因：** 列表和卡片只写「失败」。点「看日志」弹窗展示 `fail_reason` 与 `error_code`（有则显示）。
4. **即时任务：** 同样只用三态，进度用「步骤 + 百分比」。去掉取消和续跑；部分成功算失败。去掉账号列和额度说明，示例里不再出现「豆包-02」预留额度。
5. **API 生图额度不限（覆盖评估里「用完即失败 / 0 为不限额」的改法）：** 设置页去掉「每日最多生成多少张」和「用完后等到次日 / 已用完」说明；全站去掉相关 chips 与规则。任务不会因额度失败。已删除 `api_daily_limit_reached` 示例。仍保留 API 兜底开关，打开后额度不限。
6. **CS 信息不进 BS：** 顶栏去掉「本机运行 · 127.0.0.1 / Worker 在线」，「待处理 N」改为「等待 N」。侧栏脚注同步去掉本机地址。系统页 Health 只留 API 服务、调度器、数据库、磁盘、版本；Doctor 只留 Python 依赖、环境变量（LLM_API_KEY / ARK_API_KEY）、数据目录写权限、磁盘、时区。去掉形态 A、浏览器锁、Playwright、豆包 profile、`AIGEN_LOCAL_TOKEN`。
7. **豆包生图选项继续置灰：** CS 不在线时豆包不可选，并提示改用 API（本版示例默认未连接，便于直接看到置灰；未在顶栏恢复 CS 连接芯片）。不按评估建议改成常亮。
8. **营销页：** 状态示例改成「等待 / 成功 / 失败」，去掉等待态组和取消 / 续跑；去掉豆包额度条、已用完、不限额、等到次日等文案。架构脚注改为「控制面在云端，浏览器动作在本地执行端」。
9. **提示词以哪套为准：** 按项总「稍后再定」，本版不改。
