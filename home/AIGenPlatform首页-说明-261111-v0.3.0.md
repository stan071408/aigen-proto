# AIGenPlatform 首页 · 方案3 v0.3.0 · 说明（2026-11-11 北京时间）

依据：项总对 v0.2.0 的反馈「1. 这个页面没有注册入口啊，并且没有关闭按钮。2. 添加一个测试账号：admin/admin」。
本版只改登录页，首页、工作台、占位页都没动。v0.3.0 是在 v0.2.0 基础上另存的新文件，旧文件全部保留。

- 页面：`AIGenPlatform首页-方案3能力宫格型-261111-v0.3.0.html`
- 截图：`shots/AIGenPlatform首页-方案3-*-261111-v0.3.0.png`

## 本版变更
1. **关闭按钮**
   - 登录卡片右上角加了圆形浅灰底的「×」，鼠标悬停时变深，aria-label 为「关闭」。
   - 点「×」或按 Esc 都会回到营销首页（#home）。点卡片外面的背景不会关闭。
   - 卡片头部右侧的「示例 · 原型」往左让开了位置，和「×」不重叠。
   - 原来右上角的「返回首页」按钮保留。
2. **注册入口与注册视图**
   - 登录按钮下方居中加了「还没有账号？立即注册」。点击后在同一张卡片内切到注册视图，地址变为 `#register`，浏览器前进、后退都能用。
   - 注册视图同样有「×」，底部有「已有账号？去登录」。
   - 注册表单的输入框、圆角、蓝色和登录页一致，包含：
     - 账号名（必填，4–20 位字母、数字或下划线）
     - 手机号（必填，11 位，旁边有「获取验证码」，60 秒倒计时只是示意，不会发短信）
     - 验证码（4–6 位数字）
     - 设置密码（至少 6 位，带眼睛按钮）
     - 确认密码（带眼睛按钮）
     - 勾选框「注册即视为您已阅读并同意 服务条款 和 隐私政策」（选了勾选框而不是纯声明文字）
     - 蓝色「注册」按钮
   - 校验：空项、格式错误、两次密码不一致、账号名已存在（admin 已存在，本次会话里注册过的也算）、未勾选同意，都会显示红色提示，重新输入后提示消失。
   - 注册成功后弹 Toast「注册成功（示例）」，自动回到登录页（账号登录标签），并回填刚注册的账号名。新账号可以直接登录。
   - 注册的账号只存在内存里，刷新页面就清空。没有用 sessionStorage。
   - 页面标注了「注册方式与审核策略待定（原型）」「验证码仅为示意，不发送短信」。没有加第三方注册、邮箱注册、邀请码。
3. **测试账号 admin / admin，登录改为真实校验**
   - 账号登录：admin / admin，以及本次会话注册的账号能登录。其它组合会在密码框下方显示红字「⚠ 账号或密码错误」，再输入就清除。
   - 账号登录标签里加了一条浅蓝提示条「测试账号：admin / admin」，右侧有「一键填入」按钮，点一下就填好账号和密码。
   - 手机号登录：11 位手机号加 4–6 位数字验证码就能进入，格式不对会显示红色提示。页内标注「手机号登录原型：任意 11 位手机号 + 4–6 位数字验证码即可进入（不发送短信）」。
   - 原来的标签「原型：任意非空输入即可登录」改为「原型：测试账号 admin / admin」，「登录与权限方案待定」保留。

## 占位 / 未定项
- 登录方式、账号体系、角色权限：**待定**（admin / admin 只是演示用的测试账号）。
- 注册方式与审核策略：**待定**。例如是否开放自助注册、是否需要管理员审核、手机号是否必须。
- 短信验证码通道：待定。目前不发短信，倒计时只是示意，也不校验验证码是否正确。
- 账号名规则（4–20 位字母、数字、下划线）和密码规则（至少 6 位）：按本次要求先这样做，正式规则待定。
- 服务条款、隐私政策的正文：待提供（点击只弹 Toast）。
- 登录态、注册数据都只存在内存里，刷新后清空；要不要持久化待定。
- 没有做找回密码、第三方登录、邮箱注册、邀请码。

- 提示：测试账号提示条、底部两条标签文案、「立即注册」入口都在。
- 尺寸：1366×768 和 1920×1080 下，登录卡片和注册卡片（包括校验报错时）都完整显示，卡片内没有溢出或滚动条。
- 账号登录：admin + 错误密码、不存在的账号都会显示红字「账号或密码错误」，输入后清除；空提交报错；「一键填入」正常；眼睛按钮正常。
- 手机号登录：非 11 位手机号、验证码不是 4–6 位数字时报错；倒计时正常；11 位手机号 + 4 位验证码能进入。
- 注册：前进、后退、「去登录」切换正常；空提交时各项（含勾选框）都报错；格式错误报错；admin 已存在、两次密码不一致、未勾选同意都报错，提示为红色；注册页验证码倒计时和眼睛按钮正常。

- admin / admin 能登录工作台，侧栏出现，6 个 KPI 都在。
- 回归：首页无侧栏、侧栏折叠、占位页 B 式导航、其它导航弹 Toast、工作台里按 Esc 不会误退出、退出登录都正常。
- 两种分辨率下都没有控制台报错。
