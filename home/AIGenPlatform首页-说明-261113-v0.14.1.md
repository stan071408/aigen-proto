## BS / CS 分工（结论摘要，供小勾出接口清单）

**BS 只显示 BS 信息；CS 包含 BS 全部能力，可以显示任何信息。** 本原型先做 BS 端。发布只能走 CS 架构，相关设计从本原型移除，改由 CS 实现。

**留在 BS**

- 工作台导航与总览、图文生成画布（第 1 步标题来源「平台热榜」保留，仅去掉独立热榜导航）、内容库、任务中心（仅「定时图文生成」的任务设置与任务监控）。
- 设置：生成默认值、**API 兜底开关**（默认关闭）和 **每日最多生成多少张**（不预设数值；未填上限时开关不可打开）、提示词版本只读、密钥是否已配置（掩码，不可看明文）。对应 `PUT /api/settings/api-fallback`（账号级 `{enabled:false, daily_image_limit:null}`）。
- 首页与额度卡只展示 API 张数：`GET /api/quota/api-images` 字段 `daily_image_limit` / `used_today` / `remaining`。已设上限时显示「API 今日已生成 N / 上限 M 张」，未设时显示「未设置上限」。不展示豆包账号与豆包额度。买断制，界面不出现金额。
- 内容库只读「发布状态」：已发平台和文章链接（如「头条号 · 已发布 ↗」），未发布灰字「未发布」，失败显示「发布失败」。无发布/排期操作。提示文字不提连接端名称。
- 生图方式为「豆包」「API」两项，平常都可选择。配图/封面标注「豆包浏览器生成」或「API 生成」（画布结果、内容库卡片封面、详情抽屉配图，样式统一，不遮挡封面左上来源和右上状态）。
- 任务中心新建/编辑生成抽屉：「API 兜底：跟随设置 / 开 / 关」，默认跟随设置。对应任务字段 `api_fallback: inherit/on/off`。
- 任务监控「挂起」状态（灰色胶囊），说明「生图通道不可用超 30 分钟，已挂起」，操作「继续」。分组行计数兼容挂起条数。文案不提连接端名称。

**移至 CS（接口与能力清单）**

1. 发布中心整页：立即发、定时发、按点位排期、发布队列、失败重试、需人工处理、排期日历、渠道能力说明。
2. 设置中的发布项：头条多账号发布规则、微信公众号发布。
3. 任务中心「定时图文发布」及新建/编辑发布抽屉、发布监控记录。
4. 内容库「发布」「发布/排期」操作按钮；BS 不再发起发布，只读展示回写状态与链接。
5. 「已排期 / 发布中」过程态与排期筛选（排期在 CS）。
6. 图文生成 / 画布上的发布入口（如有）。
7. 首页发布统计 KPI、今日发布排期/队列、待处理中的发布失败/需人工、publish 类任务。
8. 营销首页中的发布中心卡、多账号串行发布、发布矩阵、流程发布段、架构图发布排期等表述。
9. **豆包账号登录 / 管理**：账号池、有头浏览器登录与重登、停用/启用、各账号每日上限、换号与风控。页面「账号与额度」已从 BS 去掉。
10. 发布账号（头条 / 公众号）的登录、排序与类型管理。
11. 环境变量 `WECHAT_APPID` / `WECHAT_APPSECRET` 的配置与系统自检。
12. 豆包生图的实际执行与连接态；连接态只给服务端内部判断或 CS 本地显示，**不在 BS 前端展示**（本版已去掉顶栏「已连接 / 未连接」演示开关，以及生图方式里「需客户端在线」字样和置灰逻辑）。
13. 向 BS 回写内容库发布状态：已发平台、文章链接、失败信息。
14. **本版从 BS 再移出的信息：** 顶栏连接态演示；首页豆包剩余额度与豆包账号额度看板；生图方式中的连接约束、置灰与「未连接则默认 API」提示；发布状态提示里指向回写端的字样；豆包额度快照（仅服务端内部用，见 `PUT /api/cs/doubao-quota`）。

**待项总确认**

- 任务监控二级分组：本版按「执行该次任务时使用的豆包生图账号」归组（等待中的记录用计划使用的账号）。生成任务没有发布账号。是否改为「任务所属账号」或其他口径，待确认。

## 相对 v0.14.0

### 1. 去掉 BS 上的连接端信息

顶栏不再提供连接态演示开关。首页去掉豆包剩余额度和豆包账号展示，只保留 API 张数。生图方式改回「豆包」「API」两项，均可选择，不再置灰、不再写「需客户端在线」。可见文案不出现该连接端名称。内容库只读发布状态列保持不变，提示改为「发布状态为只读信息」。

### 2. 图片来源标识

画布配图结果、内容库卡片封面、详情抽屉配图，与原有「封面 · 示例图」「点位 N」「配图 N」小标合并，标明「豆包浏览器生成」或「API 生成」。不覆盖卡片封面左上来源和右上发布状态。示例数据两种来源都有。

### 3. 买断制：去掉金额，API 兜底按张计

AGP 为买断制。全站可见文案去掉「预算」、金额、¥、「元」。设置增加「API 兜底」开关（默认关闭）和「每日最多生成多少张」（数字框，单位「张」，占位符提示填写，不预设）。上限未填时开关置灰不可打开，并有一行小字提示。首页与额度卡显示「API 今日已生成 N / 上限 M 张」，未设上限时显示「未设置上限」。原「预算用尽」类文案改为「今日 API 张数已用完」。

### 4. 任务抽屉与监控

新建/编辑生成抽屉增加「API 兜底：跟随设置 / 开 / 关」，默认跟随设置，使用站内分段控件。任务监控增加「挂起」状态（灰色胶囊，区别于等待/运行中/成功/失败），说明「生图通道不可用超 30 分钟，已挂起」，操作「继续」；示例至少一条，分组计数含挂起。

层级区分、标签/值区分、同功能样式统一、控件规范 v0.2.0、占位撑满到视口底约 20px 且可滚动、沙箱不用原生 form submit，均保持。
