## 改动要点

1. 内容库文章详情抽屉宽度由 520px 增至 720px（+200px），并以 `min(720px, 92vw)` 限制，1366 下不超出视口。其它抽屉仍为 520px。
2. 「来源 / 字数 / 生成时间 / 格式」改为一行四等分，标签在上、值在下。「产物」已改名为「格式」，值仍为 docx / md / html 小胶囊。内容库列表视图原先没有「产物」列，无需改表头。
3. 配图区随加宽按三列放大；去掉图片卡底部重复的编号行，仅保留「点位 N」标签；配图容器不再使用会带青绿底的 `g3` 类，背景与抽屉白底统一。
4. 最下方「正文预览」改为与 3.3 相同的折叠标题栏（复用 `s33-preview` / `pv-head` / `pv-pill-type` / `pv-pill-cat` / `pv-words` / `pv-chevron`）：「&lt;来源&gt;正文预览」+ 蓝色来源胶囊 + 灰色分类胶囊，右侧字数与箭头。默认展开，可折叠查看正文纸面；底部「复制正文 / 发布 · 排期」仍固定在抽屉脚，不被遮挡。
