## 相对 v0.17.2

1. **总览页改为方案 A 三段式**（数据全部取主原型现有示例数据，非写死）：
   - 第一排四张 KPI：**总生成文章 / 总生成图片 / 待执行任务数 / 失败任务数**，点击分别跳到内容库（含图片筛选）、任务中心（等待 / 失败筛选）。

   - 第二排右：**今日执行流水**（时间 + 状态胶囊 + 标题 + 来源），按日期分组、最多两日、每行可读；右上「任务中心 →」。
   - 第三排：**最近产物**三张封面卡（标题 + 封面胶囊；底栏 时间 · 字数 · 共N张图 · docx · 生成来源 · 导出本稿），点击进内容库详情抽屉。
2. 原总览的「待处理」「API 今日已生成」「近期任务」三块被方案 A 取代；API 额度信息仍在设置页，BBS 规则不变。
3. 新增 CSS 均在 `#pageHost` / `.hm-` 前缀下，不影响内容库、任务中心、设置等页面。
