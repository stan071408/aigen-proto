产品定位

面向自媒体内容生产的 B/S 图文生成平台

AIGenPlatform 把选题、写稿、配图、发布放进同一个浏览器工作台。按「云端控制面 + 本地执行代理」设计：豆包生图、头条 / 公众号发布、各类登录这些浏览器动作，都在执行机本地完成。

能力 01 · 图文生成

从一个主题，写到一篇图文

简报画布把创作拆成 4 个主步骤；深度加工展开 5 个子步骤，内部共 8 步。原稿先落地，再决定怎样继续表达。

  • 主题生成标题，或直接指定标题
  • 原稿可同时去 AI 化
  • 深度加工：核心立意 + 写作风格 → 三稿 → 合稿
  • 进入图文生成，配图与正文围绕同一表达

能力 02 · AI 热榜图文生成

从平台榜单出发，写自己的观点

采集头条热榜、百度热搜的原标题，选一条提炼核心立意，再沿用同一套风格、三稿、合稿流程。

  • 采集平台可多选，主题方向可留空
  • 实际数量 ≤ 设定数量，不用重复内容凑数
  • 空结果 / 采集失败 / 数量不足都有明确提示

全流程

选题 → 原稿 → 深度加工 → 三稿 → 出图 → 发布

每一步都有独立的设置、日志和结果区，任务在后台运行，进度实时推送。

  • 可选步骤可以跳过，必经步骤不能省
  • 三个方向都完成后才能合并三稿
  • 任务可取消、可续跑

多账号

额度按张算，发布按号排

豆包多账号按图片张数计额度，头条多账号串行发布、限频，公众号企业号走官方接口。

  • 每个豆包账号单独设每日上限，全部用满后用 API 兜底
  • API 兜底必须设每日预算，用完任务挂起到次日
  • 头条每号每日默认 5 篇，新号 / 近期被风控号 3 篇
