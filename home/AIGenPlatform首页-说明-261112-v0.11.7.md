## 本版改动

1. **顶栏只显示当前页名称**  
   「工作台 / 创作 / 图文生成」改为一级标题「图文生成」。总览、AI 热榜图文生成、内容库、任务中心、发布中心、账号与额度、设置、系统同样只显示自身名称，不再带「工作台 / 创作 / 管理 / 系统」前缀。面包屑顶栏保留。

2. **调试阶段默认跳过登录**  
   打开文件即已登录测试账号，直接进入工作台「图文生成」（`#app/article`）。若地址栏已是其他工作台 hash（如 `#app/hot`、`#app` 总览），则停在对应页。  
   开关在外壳脚本顶部：`const DEBUG_SKIP_LOGIN = true;`，改成 `false` 即恢复首页 / 登录页。主动进入 `#login`、退出登录仍可用。

3. **第 2 步空状态撑满画布剩余高度**  
   生成原稿前，「这篇文章，从原稿开始」所在白卡向下撑到画布底部，不再留下大块灰色空白；文案在区域内垂直居中。1366×768 与 1920×1080 下第 2 步不因此出现额外滚动。高度按视口计算，不是写死的占位；原稿出来后由预览替换，上方设置区不跳动。热榜若出现第 2 步空状态，同一套规则生效（热榜模块选榜后会直接进入深度加工，无第 2 步生成流程）。

4. **生成原稿后，正文预览撑满一屏，三按钮同屏可见**  
   生成完成后自动滚到「原稿正文预览」，预览卡顶距画布顶 ≤ 24px。预览正文高度 = 画布可视高度 − 预览标题行 − 底部三按钮（导出本稿 / 进入图文生成 / 原稿深度加工）− 边距；正文在框内滚动。窗口缩放会重算。折叠预览仍可用且上方不跳动。平台热榜入口若在预览上方还有候选标题，滚入后仍是「预览 + 按钮」占满一屏。热榜模块第 2 步同样适用。

5. **3.1 选核心立意后立即进入 3.2**  
   在结果里点选一条核心立意，立即进入 3.2 写作风格，并平滑滚动到 3.2 步骤标题（图一红框位置，位于画布顶部）。改选另一条立意同样跳到 3.2；若会清空后续结果，仍走原来的确认框，确认后再跳。热榜同样。

6. **3.2 设置区收紧**  
   图二红框（来源卡片、已选文章标题 / 已选核心立意、分隔和「写作风格数量 + 获取写作风格」）整体更紧凑：来源卡片约 56–64px，已选标题与取值同一行，间距与分隔收紧。数量输入保持 36px，主按钮保持 40px。  
   1366×768 实测（设置卡 `.zn-set`）：改前 **298px**，改后 **193px**，约合 **−35%**。来源卡片 74px → 56px，已选信息块 117px → 54px。

7. **3.2 选写作风格后立即进入 3.3**  
   在结果里点选一种写作风格，立即进入 3.3 生成三稿，并平滑滚动到 3.3 步骤标题（图三，位于画布顶部）。热榜同样。  
   「不跳动」现在只约束 3.2 的来源单选（根据原标题获取 / 从已有风格中选择）：切换这两项时页面不跳。
