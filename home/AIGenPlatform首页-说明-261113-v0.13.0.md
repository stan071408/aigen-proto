## 页面结构

- 一级按钮（样式与内容库 v0.12.10 一级完全一致）：「定时图文生成」「定时图文发布」
- 二级胶囊（复用热榜采集平台 `.hot-plat`，放在浅底缩进行 `.lib-row-sub`）：「定时任务设置」「任务监控」
- 定时任务设置：任务列表（任务名、参数摘要、执行周期、下次执行、启用开关、编辑 / 立即执行 / 删除，删除二次确认）+「新建任务」抽屉
- 任务监控：今日执行 / 成功 / 失败 / 运行中 四张统计小卡 + 执行记录（开始时间、状态、耗时、产出链到内容库或发布结果；失败可重试 / 看日志）
- 无任务 / 无记录时用与内容库一致的空占位，撑满到视口底约 20px，页面可滚动

## 新建「定时图文生成」面板字段

任务名；标题来源（主题生成 / 平台热榜 / 直接指定，及对应主题、热榜方向或指定标题）；标题数；去AI化；深度加工（勾选后展开立意数、写作风格、是否生成三稿并合并）；配图方式；配图数量（默认封面 1 + 配图 5）；定时（单次 / 每天 / 每周 / 自定义 + 时间）。数字框复用画布 `ctl-step`。

## 新建「定时图文发布」面板字段

任务名；从内容库选文章（来源过滤 + 搜索标题，样式复用内容库二级胶囊与列表）；发布平台；发布账号；发布时间（单次 / 每天 / 每周 / 自定义 + 时间）。

新建 / 编辑沿用右侧抽屉，宽度与内容库文章抽屉一致（`min(720px, 92vw)`）；外框 overflow hidden，仅正文区滚动，避免滚动条切到内角。抽屉本身是全高贴右边，与现有抽屉一样外框无圆角。全部 `type="button"`，不使用原生 form submit，沙箱 iframe 可用。若项总希望改为居中圆角弹窗，可再出修订。

## 示例数据

- 生成任务 4 条：社区民生日更、平台热榜早报、指定稿·智能设备、周末深度稿（含停用）
- 发布任务 3 条：头条晚间发布、公众号单次发布、周五合集发布（含停用）
- 标题与内容库示例对应：社区食堂如何留住居民、老旧小区加装电梯…、智能设备越多…、养老金调整…、小城书店如何留住不同年龄的读者
- 执行记录覆盖等待 / 运行中 / 成功 / 失败；左侧「任务中心」角标 = 等待 + 运行中记录数（当前为 3）
- 新建 / 编辑 / 开关 / 删除 / 立即执行 / 重试 / 看日志在原型内可交互（内存态）
