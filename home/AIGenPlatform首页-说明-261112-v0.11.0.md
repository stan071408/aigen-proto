## 没能统一的地方和原因

1. **管理页筛选分段 `.seg`（白底选中）没有改成实心主色蓝。** 规范里的「一级标签」是来源切换那种分段控件，以及首页模块标签。内容库 / 任务中心等页内筛选是次级分段，若也改成实心蓝，会和页面一级操作抢层级。只把圆角调到 12。
2. **工作台普通 `.btn` 仍是 1px `--line` 灰边，没有全部改成次要按钮的 1px 主色蓝描边。** 主色描边留给「取消 / 重试」这类明确的次要操作，避免顶栏、表格操作钮都变成品牌描边。
3. **登录 / 注册输入用大档 40，而不是中档 36。** 独立账号页需要稍高的触控区域；描边、圆角、光圈已与画布同一套令牌。
4. **营销首页的 `.btn-w`、`.btn-ghost` 等宣传按钮未改。** 那是首页招贴风格，不是工作台表单控件。
5. **图文第 1 步出结果后的 `input.topic` 仍可能是 40px（原有规则）。** 为避免扰动已对准的三种设置卡等高，这一处没有动。热榜 #hotTopic 已经是 36。
6. **没有拆开历史遗留的 `.adash { … }` 大块嵌套。** 工作台组件样式从 v0.10.1 起就写在未闭合的 `.adash` 声明后面，实际是套在管理壳里。若强行补上 `}`，选择器会漏到营销首页，可能冲掉首页已有的 `.card` / `.tabs`。登录注册的勾选因此补了一条全局规则，而不是去改这段结构。
