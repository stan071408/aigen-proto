# AIGenPlatform 首页 · 方案3 能力宫格型 · v0.17.5

- 日期：2026-11-18（北京时间）
- 基于：v0.17.4（旧版不覆盖）
- 范围：重写总览柱状图的布局方式，修「柱子溢出面板、压住正文」的异常。

## 问题根因

v0.17.4 的柱图用「横向 flex 容器 + 每列 flex 列 + `justify-content:flex-end`」实现底部对齐；在真实浏览器里，列高度被内容撑开、且在 172px 容器里向上溢出，导致柱子跑到页面顶部、压住「内容与产物 / 总览」和 KPI 卡片（列宽也被压到 27px）。

## 修法

改成 **CSS Grid 两行布局**，不依赖 flex 对齐：

- `.hm-chart`：`grid-template-columns: repeat(7, minmax(0,1fr))`（7 列）＋两行（柱体 1fr / 日期 16px），高 196px；
- 每根柱 `.hm-bar`：`display:flex; flex-direction:column-reverse`（文章在下、失败在上），`align-self:end` 底部对齐，宽度撑满列；
- 柱段高度按当天最大值等比缩放到 150px 内，段间 3px 间隙、6px 圆角；
- 日期 `.hm-lb` 单独占第二行，居中。

实测 1280 / 1366 / 1508 / 1920 四种宽度：柱宽 59–107px、全部落在图表面板内（无一溢出）、无横向溢出。

其余保持 v0.17.4：四张 KPI、两个面板等高 330px、流水内滚动、「全部 / 文章 / 图片」「全部 / 执行中 / 失败」切换、最近产物 3 张 168px。
