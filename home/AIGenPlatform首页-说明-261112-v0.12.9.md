## 改动要点

1. 去掉内容库图片卡片及详情抽屉中的「重新生成」按钮与相关文案；不再从内容库发起单图重生成。
2. 顶部筛选栏重做（去掉原「文章 / 图片 / 文档产物」页签和「图文」「全部状态」下拉）：
   - 数据类型：「文章」与「短视频（即将支持）」；短视频灰显不可点，带「即将支持」小标。
   - 右侧图标分段切换「卡片视图 / 列表视图」，两种都能用。
   - 浏览文章时可按来源单选过滤（全部 / 原稿 / 差异化稿 / 广度稿 / 深度稿 / 合并稿）并搜索标题；过滤与搜索实时生效。
3. 卡片视图沿用图三封面卡片网格，元信息保留所属模块、时间、字数、图片数和产物标签，并显示来源。列表视图为图四风格表格，列为 标题 / 来源 / 所属模块 / 生成时间 / 字数 / 操作（导出走已有「导出示例文章」弹窗）。
4. 无结果时给出空占位，并撑满到视口底约 20px；仍可滚动。
